# زندگی‌یار | Life OS

برنامه شخصی فارسی و راست‌چین برای مدیریت عادت‌ها، کارها، اهداف، امور مالی، یادگیری و دفتر روزانه. این نسخه برای GitHub Pages به‌صورت PWA آماده شده است.

## فایل‌ها
- `index.html`: رابط کاربری و منطق برنامه
- `icon.svg`: نشان اختصاصی زندگی‌یار
- `manifest.webmanifest`: تنظیمات نصب روی موبایل
- `sw.js`: سرویس‌ورکر با راهبرد شبکه‌اول برای صفحات و کش نسخه‌بندی‌شده

## انتشار روی GitHub Pages
1. فایل‌ها را در ریشه یک مخزن GitHub بارگذاری کنید.
2. از Settings → Pages، گزینه Deploy from a branch، شاخه `main` و پوشه `/ (root)` را انتخاب کنید.
3. پس از نمایش Your site is live، آدرس منتشرشده را باز کنید.

## قابلیت‌ها
- داشبورد، ثبت و پیگیری عادت‌ها، کارها و هدف اصلی
- ثبت درآمد و هزینه، جلسات یادگیری و دفتر روزانه
- گزارش ماهانه CSV/JSON و پشتیبان‌گیری/بازیابی JSON
- ذخیره محلی با `localStorage` و استفاده آفلاین از پوسته برنامه
- ثبت‌نام/ورود ایمیلی و همگام‌سازی دستی با Supabase (در تنظیمات)

## امنیت و داده
کلید استفاده‌شده در مرورگر، کلید عمومی `publishable` است؛ کلید `service_role` هرگز نباید در برنامه سمت کاربر قرار گیرد. دسترسی داده‌ها باید با RLS و سیاست‌های محدود به `auth.uid()` کنترل شود. پیش از استفاده عمومی، تنظیمات تأیید ایمیل، بازیابی گذرواژه، سیاست‌های RLS و هشدارهای امنیتی پروژه را بازبینی کنید.

داده‌های برنامه ابتدا روی دستگاه ذخیره می‌شوند. ورود/خروج باعث پاک‌شدن داده محلی نمی‌شود. همگام‌سازی ابری فقط با اقدام کاربر انجام می‌شود. پیش از استفاده روی چند دستگاه، از داده‌ها خروجی پشتیبان تهیه کنید.

## تست‌های انجام‌شده در بسته
- بررسی نحوی همه اسکریپت‌های جاوااسکریپت با `node --check`
- بررسی ساختار فایل manifest و وجود فایل‌های موردنیاز PWA
- بررسی وجود جدول‌ها و کلیدهای همگام‌سازی در پروژه Supabase متصل

تست تعاملی کامل در مرورگر واقعی و آزمون ثبت‌نام با ایمیل تأییدشده، قبل از انتشار عمومی همچنان لازم است.
